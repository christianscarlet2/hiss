Hiss — the bot's Table Display server WEB

http://127.0.0.1:27654 (localhost only; falls back to 27655–27663 if busy). Starts automatically with Hiss — watch the chat terminal for "Terminal API server listening on http://127.0.0.1:27654". Served by Hiss/ChatTerminalServer.cpp; front-end in laravel-react-table-display/public/.

Table Display /table-display/

  • Live table view, refreshes ~2×/sec: seats (2–10) with name + matched PT4 name, hole cards (back/?? when unknown), active dot, balance, bet, dealer button.
  • Community cards, hand number, small/big blind, ante, pot, game type, Omaha flag.
  • PokerTracker 4 HUD stats per player (shown once the name is verified).

OCR Name Mappings /mappings/

  • Table of OCR-detected → real PT4 names: OCR, Actual, Site, Verified, Confidence, Updated.
  • Live filters (by OCR text / by actual name), "show unverified only".
  • Per row: Verify / Unverify / Delete; Refresh to reload.

Endpoints (data / terminal)

  • /api/table-state — full game-state JSON (what the Table Display renders).
  • /api/mappings, /api/mappings/verify|unverify|delete?id=.
  • /append · /stream · /clear — write/clear the bot terminal sections (context / state / decisions / chat) via ?text=&section=.

Training Samples /trainer/

  • Build Tesseract OCR samples (sample_NNNN.png + .gt.txt).
  • Transform dropdown (AutoOcr0/1 or Text0–Text9; re-recognizes all rows, shows font counts), "Hide saved".
  • Per row: image, editable text, save one, delete one, clear-underneath. Toolbar: Delete Duplicates, Clear All, Save All, "Create Fonts…".

Create Fonts /trainer/fonts.html

  • Capture scrapes → segment live balance regions into glyphs; label each to build bitmap fonts (t$ records).
  • Per row: glyph / reference / scrape images, char input (creates font + rescans), group dropdown, Apply Group Below, per-row 🎨 colour editor (eyedropper + magnifier + A/R/G/B/radius), delete.
  • Global colour toolbar: ⊙ Eyedropper (pick from any Reference/Scrape), A/R/G/B/Radius + swatch, Apply to group, Apply to all regions, Help.
  • Undo (Ctrl+Z), Clear All, Delete All from .tm (writes .tm.bak first), Save All.

ManualMode-XMLRPC — game-control API API

XML-RPC over HTTP on port 9092 (ManualMode-XMLRPC/xmlrpc.cpp). Call it from a script/client — not a browser page. Drives a simulated table and reads the bot's decision.
  • Set state: SetSeated/SetActive/SetDealer/SetBalance/SetBet, SetSBlind/SetBBlind/SetAnte/SetPot/SetGType/SetHandNumber/SetNetwork/SetTournament, SetCards/SetFlopCards/SetTurnCard/SetRiverCard, SetName, PostSB/PostBB.
  • Drive actions: DoFold/DoCall/DoRaise/DoAllin, SetButton, Refresh.
  • Read decision: GetAction → {button:F/C/K/R/A, betsize}, CancelGetAction, Quit.

Hopper IPC — launcher control IPC

Win32 window messages (Hiss/COpenHoldemHopperCommunication.cpp). Internal launcher↔bot only; no browser/network.
  • Connect / disconnect a table, get connected HWND, set/reset user flags (0–19), query readiness.
  • Read a symbol value via WM_COPYDATA (magic 424242).

Ports: Hiss Table Display 27654 · Trainer 28700 · ManualMode-XMLRPC 9092. All HTTP servers bind localhost only.
