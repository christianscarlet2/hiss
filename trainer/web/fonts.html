Global colour picker

Sets one colour cube (the A/R/G/B centre + radius) for every pending glyph in a font group at once, then re-segments those glyphs with it.

  1. Set the colour. Click ⊙ Eyedropper, then click any row's Reference or Scrape image to grab that pixel's colour (a magnifier follows the cursor). Or type A, R, G, B (0–255) directly. Radius is the colour-cube tolerance — a pixel is foreground when its Euclidean distance from the centre colour is ≤ radius (same rule as Vision; a negative radius inverts it).
  2. Apply to group — every pending row whose Group is the selected Text<n> is re-binarised with this colour, and the colour/radius are saved to each of those glyphs' region r$ records.
  3. Apply to all regions — writes this colour/radius to every balance region's r$, even ones that currently scrape nothing, then regenerates all pending glyphs. Use this to fix capture when some regions have the wrong colour: eyedrop a good colour from a working scrape, click this, then Capture scrapes again.

All colour changes are saved to the tablemap so live recognition binarises with the same colour. The per-row 🎨 editor does the same thing for a single glyph.
