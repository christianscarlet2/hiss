Global colour picker

Sets one colour cube (the A/R/G/B centre + radius) for every pending glyph in a font group at once, then re-segments those glyphs with it.

  1. Enter the colour as A, R, G, B (0–255) and a Radius (the colour-cube tolerance; a pixel is foreground when its Euclidean distance from the centre colour is ≤ radius — same rule as Vision. A negative radius inverts the test).
  2. Pick the font group (Text0–Text9). Selecting a group pre-fills the fields from a tablemap region that uses that transform, so you usually only need to tweak.
  3. Click Apply to group. Every row whose Group is that Text<n> is re-binarised with this colour, and the colour/radius are written back to each glyph's region r$ record so live recognition uses the same colour.

Tip: to grab an exact colour from a real scrape, open a row's 🎨 editor and click a pixel on the Reference or Scrape image — then copy those A/R/G/B values up here to apply group-wide.
